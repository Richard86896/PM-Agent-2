一句话方案

把 收询盘 → AI 识别+多语言起草 → 飞书审核 → 一键回复 串成一条流水线；AI 只起草不自动发，禁止编造价格交期，销售确认后才发出。

01

多语言自动起草

收到询盘秒级识别意图与语言，用客户语言生成专业回复草稿，价格 / 交期留占位待销售填。

02

人工闸门 + 合规护栏

草稿先置「待审核」，销售在飞书卡片点确认才发；禁止 AI 编造报价、交期、保修承诺。

03

线索打分 + 不丢失

按意向给线索 0–100 打分，高意向优先跟；展会名片拍照即 OCR 入库，沉默客户自动提醒跟进。

询盘处理主流程

从一条询盘到一次合规回复

接收询盘 WEBHOOK

客户 WhatsApp / Telegram 消息进入工作流。

解析 + 查线索库 CODE

提取号码 / 昵称 / 正文，查飞书是否已有该客户。

AI 识别 + 起草 + 打分 AI

识别意图、检测语言、生成对应语言回复、按意向 0–100 打分。

写入飞书线索库 CODE

线索 + 草稿 + 评分写入，状态置「待审核」。

推送审核卡片 飞书

带评分 + 草稿 + 确认按钮的卡片推到销售群。

人工确认 → 发送 HUMAN

销售点「确认发送」，回复真实发回客户，状态转「已发送」。

合规护栏 · 核心价值

AI 辅助人,但人始终在闸门上

人工闸门
AI 草稿全部「待审核」，发送动作只由销售点击触发，不自动回复客户
禁止编造
价格 / 交期 / MOQ / 折扣一律不生成，用「待销售填写」占位，由销售补
禁止承诺
不承诺保修、退换、时间保证等任何越权内容
线索分级
高意向优先跟、垃圾线索自动归档，销售把精力放在对的客户上
